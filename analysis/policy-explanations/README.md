# Three-level plan explanation

Run the bundled real LLM-generated Mia example from the repository root:

```bash
python -B analysis/policy-explanations/run_explanations.py --paths 1000
```

Open `analysis/policy-explanations/results/mia_explanation.html`. The JSON beside it contains all action probabilities, masks and model inputs used for the comparisons. The example plan was generated by Qwen; it is matched to the bundled Mia profile, not to any synthetic profile. Its two saved versions are a draft and a revision to a different user message; they are not repeated samples under identical conditions.

To analyse an existing saved synthetic-profile plan:

```bash
python -B analysis/policy-explanations/run_explanations.py --profile P00001 --paths 1000
```

This looks for `twin/artifacts/plans/P00001.json`. Use `--plan-file PATH` for another saved plan, and `--version 1` to select a full historical version. The caller must ensure a custom plan belongs to the selected profile. Use `--low-cash 3000` to choose the hypothetical cash value, and `--out PATH` to redirect report outputs.

## Optional live LLM experiment

The bundled analysis does not query an LLM. To compare repeated live planner drafts at low and baseline cash, configure the project's `TOGETHER_API_KEY` and `TOGETHER_MODEL`, and deliberately request live calls:

```bash
python -B analysis/policy-explanations/run_explanations.py --live-samples 10 --wishes "I want to balance my goals and savings"
```

This makes at least 20 LLM planner runs; each can use up to four LLM calls and includes simulator feedback. It sends the planner's profile and state context to the configured provider and may incur costs. Sample counts are frequencies of step presence somewhere in the generated plans, not monthly action probabilities. Wilson intervals for each frequency and conservative intervals for their independent-group difference reflect finite sample uncertainty, conditional on the prompts, provider settings and planner; small samples give wide intervals. Different features may naturally co-occur in a plan. The model may respond inconsistently or return invalid plans, in which case the run can fail; no fake results are substituted.

## Interpretation

The report separates (1) the LLM's saved plan and revisions, (2) conditional one-step rule-policy probabilities and per-path plan-step logs, and (3) paired plan-versus-habit simulations plus offer-probability stresses. Each plan step's commitment is not the same as its realised completion rate. State perturbations recompute derived quantities, plan triggers and action masks. Model-suggested reasons are not evidence of its internal reasoning; input perturbations are not established real-world causal effects. The plan-versus-habit outcome comparison changes multiple intentions and spontaneity simultaneously. 95% intervals describe Monte Carlo error conditional on the simulator, not full forecast uncertainty. Later-dated plan revisions are projected over the full 2025–2034 horizon, so they must not be read as historical forecasts.
