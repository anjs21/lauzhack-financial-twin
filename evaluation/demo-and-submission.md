# Suggested Demo and Submission Guide

**LauzHack 2026 | Draft for organizer confirmation**

> Final submission channel, deadline, team-size rules, and demo length must be confirmed by organizers. Do not treat the examples below as official rules.

## Goal of the demonstration

Show that the Financial Twin can help someone explore a financial decision under explicit assumptions.

## Suggested demo sequence

1. **Problem and user:** Introduce a fictional person and the decision.
2. **Initial state:** Show income, expenses, assets, liabilities, or other relevant inputs.
3. **Intervention:** Change a life decision or scenario assumption.
4. **Calculation:** Show that the model recomputes the financial state.
5. **Comparison:** Explain baseline versus alternative.
6. **Trade-offs:** Highlight constraints, sensitivities, and limitations.
7. **Validation:** Demonstrate one reproducibility or consistency check.

## Suggested repository contents

- A README with setup instructions.
- Source code or an accessible prototype.
- A description of the financial model.
- Sample synthetic input data or a reproducible generator.
- Assumptions and data-source attribution.
- Instructions for reproducing at least one scenario.
- Any known limitations.

## Suggested evidence by format

| Format | Useful evidence |
|---|---|
| Financial simulator | Inputs, transition logic, comparison, tests |
| Conversational AI | Tool/calculation traces, scenario outputs, grounding |
| Computer game | Game actions linked to financial state changes |
| Multi-agent simulation | Agent definitions, interactions, state accounting |
| Reinforcement learning | Environment, actions, rewards, baselines, constraints |
| Optimization | Objective, constraints, feasible solutions, trade-offs |
| Quantum-classical | Problem formulation, circuit/simulator, classical comparison |
| Immersive experience | Interaction flow and financial model consistency |

## Example scenario

**Fictional Alexia:** age 20, Lausanne, CHF 8,000 starting cash.

Compare working immediately with pursuing a master's degree.

No ten-year numerical result can be inferred from the opening cash alone. Teams must disclose income, costs, time horizon, and other assumptions.

## Presentation guidance

- Show a working end-to-end example.
- Distinguish observed synthetic inputs from model assumptions.
- Avoid claiming guaranteed future outcomes.
- Use plain language to explain financial trade-offs.
- Be prepared to answer how calculations were validated.
