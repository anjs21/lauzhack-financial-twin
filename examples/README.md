
# Financial Twin — Examples and Inspiration

** LauzHack 2026 | AI Financial Twin Challenge**

## Welcome

This folder contains examples illustrating how a Financial Twin could help individuals explore financial decisions.

The examples are intended to inspire different technical and creative approaches.

They are not prescribed solutions, official financial recommendations, or production-ready implementations.

## What Is a Financial Twin?

A Financial Twin is an interactive computational representation of a person's financial situation.

It can help users:

- Understand their financial position
- Explore alternative life decisions
- Simulate financial consequences
- Compare possible outcomes
- Identify constraints and trade-offs
- Understand uncertainty
- Evaluate progress toward goals

**A Financial Twin is not a forecasting product.**

Its purpose is to explore conditional possibilities rather than claim to predict one certain future.

## Example User: Alexia

Alexia is a fictional 20-year-old student in Lausanne.

Starting liquid savings: CHF 8,000.

She is considering:

1. Starting work
2. Pursuing a master's degree
3. Moving abroad

Her financial future depends on assumptions about income, expenses, education, employment, and other conditions.

## Important Distinctions

- Observed data is not the same as assumed data.
- Simulation is not the same as prediction.
- Financial optimization is not the same as financial advice.
- A visual dashboard is not automatically a digital twin.
- An LLM-generated answer is not automatically a valid financial calculation.

## Responsible Development

Use synthetic or appropriately licensed public data.

Never use real UBS client data.

Make assumptions visible.

Communicate uncertainty and limitations.

Validate calculations.

## Challenge Principle

**Don't predict the future. Make it explorable.**
