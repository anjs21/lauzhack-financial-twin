Welcome! This folder answers common questions about the challenge, data, technical approaches, financial modelling, demos, and responsible use.

All technologies and external datasets are optional. A Financial Twin is an interactive representation for exploring financial decisions under explicit assumptions—not a claim to predict the future.

Start here
- The challenge is technology-neutral.
- Fictional profiles and reproducible calculations are strongly encouraged.
- Public economic data can inform assumptions but is not required.
- Financial outcomes are conditional simulations, not guaranteed forecasts.
- Check the official event announcement for binding submission rules. Repository evaluation material is labelled draft until approved.
Challenge principle: Don't predict the future. Make it explorable.
