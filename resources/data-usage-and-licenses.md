# Data Usage, Attribution and Licenses

> **Optional resources.** Teams may use the provided synthetic data, select any public dataset, create their own fictional data, or use no external data. No source, technology, method, or interface is required.

A Financial Twin explores *conditional decisions and consequences*, not a guaranteed future. All examples are educational and do not constitute financial advice.

## Before using external data

1. Confirm the link provides actual observations, a downloadable archive, or a dataset export interface.
2. Record provider, dataset name/code, geography, frequency, unit, publication date, retrieval date, and source URL.
3. Read provider-specific copyright, attribution, API and redistribution terms. **Downloadable does not necessarily mean freely redistributable.**
4. Avoid real personal financial records, secrets, credentials, and identifiable information.
5. Document filtering, imputation, conversion, resampling, and assumptions.
6. Distinguish historical observations, synthetic starting states, user choices, and simulated outcomes.
7. Check all software, model-weight, asset, and dataset licenses separately; a repository license cannot override them.

## Examples of licensing checks

- SNB: https://data.snb.ch/en (data portal and copyright information).
- Eurostat: https://ec.europa.eu/eurostat/data/bulkdownload/ (bulk dataset download).
- FSO: https://www.pxweb.bfs.admin.ch/ (individual statistical tables).
- World Bank: https://api.worldbank.org/v2/country/CHE/indicator/SP.POP.TOTL?downloadformat=csv (downloadable data).

These are starting points, not legal clearance. If reuse rights are unclear, link to the provider rather than copying its data into GitHub.

## Citation template

`Provider — Dataset title/code — Geography — Reference period — Retrieved YYYY-MM-DD — URL — Applicable license`

## For AI models and games

Local open-source software can be free, while model weights, hosted inference, GPU rental, 3D assets, and cloud services can have separate terms or costs. Respect attribution for engine dependencies and art assets.
