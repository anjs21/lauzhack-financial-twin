
# Synthetic Financial Data

**LauzHack 2026 | AI Financial Twin Challenge**

## Overview

This folder provides synthetic financial data to support the development of AI Financial Twin prototypes.

The datasets are designed to help participants represent fictional financial situations, explore decisions, simulate life events, and compare alternative scenarios.

All personal profiles and financial records are fictional.

**No real personal or confidential financial data is included or permitted.**

## Purpose

Participants may use these datasets to:

- Construct financial state representations
- Model income, expenses, assets, and liabilities
- Explore financial decisions and life events
- Build scenario simulation engines
- Evaluate financial constraints and trade-offs
- Experiment with artificial intelligence
- Develop computer games and interactive simulations
- Build agent-based or reinforcement-learning environments
- Test optimization and causal modelling approaches
- Create visual and immersive Financial Twin experiences

## Example Profile — Alexia

Alexia is a fictional 20-year-old student living in Lausanne, Switzerland.

Her initial liquid savings are CHF 8,000.

She is exploring three possible decisions:

1. Start working
2. Pursue a master's degree
3. Move abroad

The Financial Twin may compare how these decisions affect her cash flow, liquidity, savings, financial goals, and other relevant outcomes.

The data does not determine which decision is best.

## Data Relationships

Datasets can be linked using fictional profile identifiers.

For example, a profile identifier may connect:

- Personal characteristics
- Transactions
- Assets
- Liabilities
- Financial goals
- Life events

Participants may extend or transform these datasets to support their chosen architecture.

## Financial Modelling

A Financial Twin should distinguish:

- Starting financial information
- Financial decisions
- External conditions
- Modelling assumptions
- Calculated outcomes
- Uncertainty and limitations

The objective is to explore conditional consequences rather than predict one certain future.

## Technology Freedom

Participants may use any appropriate technology, including:

- Classical financial simulation
- Monte Carlo methods
- Generative AI
- Machine learning
- Reinforcement learning
- Multi-agent systems
- Optimization
- Causal inference
- Computer games and game engines
- Interactive 3D environments
- Quantum-classical research prototypes

No particular technology is required.

## Data Limitations

These datasets are synthetic examples.

They should not be interpreted as:

- Actual financial institution client records
- Representative samples of the Swiss population
- Verified Swiss household statistics
- Guaranteed future financial outcomes
- Personalized financial advice

Financial assumptions must be documented and validated before use.

## Responsible Data Use

Participants should:

1. Use only synthetic or appropriately licensed public data.
2. Never use real personal or confidential financial information.
3. Respect third-party dataset licenses.
4. Avoid exposing credentials or sensitive information.
5. Document any additional assumptions.
6. Validate financial calculations.
7. Communicate model limitations.

## Challenge Principle

**Don't predict the future. Make it explorable.**
