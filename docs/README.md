# AI Financial Twin — Documentation

Welcome to the supporting documentation for the **UBS × LauzHack 2026 AI Financial Twin Challenge**.

## Purpose

This documentation introduces the concepts and methods that may help participants build an AI-powered Financial Twin.

The objective is to help people explore the potential financial consequences of life decisions through data, modelling, simulation and explainable AI.

A Financial Twin is not intended to predict one certain future. It should enable users to compare multiple possible futures under transparent assumptions.

## Freedom to Innovate

Participants are free to choose their own technology stack, algorithms, architectures, and user experiences.

The documentation provides background and inspiration, not a prescribed implementation.

## Responsible Development

- Use synthetic or appropriately licensed public data.
- Do not use real UBS client information.
- Make assumptions and limitations transparent.
- Distinguish simulations from guaranteed forecasts.
- Avoid unsupported financial advice.

**The goal: Make financial possibilities explorable, understandable, and trustworthy.**
