# Games, 3D and Immersive Experiences

> **Optional resources.** Teams may use the provided synthetic data, select any public dataset, create their own fictional data, or use no external data. No source, technology, method, or interface is required.

A Financial Twin explores *conditional decisions and consequences*, not a guaranteed future. All examples are educational and do not constitute financial advice.

These are **optional free software projects**. Each link is an official project download page or source repository; it is not a promise of free hosted infrastructure.

## Possible Financial Twin uses

Teams may combine these tools to represent fictional financial states, calculate alternative decisions, build games or interactive simulations, compare constraints, or explain conditional outcomes. Any numerical outputs should be validated independently of generated prose.

## Selection guidance

Select based on required capabilities, available hardware, time, team skills, and licenses. No technology is required.
