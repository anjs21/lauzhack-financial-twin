Optional Public Datasets
Optional resources. Teams may use the provided synthetic data, select any public dataset, create their own fictional data, or use no external data. No source, technology, method, or interface is required.

A Financial Twin explores conditional decisions and consequences, not a guaranteed future. All examples are educational and do not constitute financial advice.
Browse by use case
- [Swiss economic data](swiss-economic-data.md): Swiss inflation, employment, macro indicators and official Swiss export portals.
- [Macroeconomic data](macroeconomic-data.md): GDP, CPI, unemployment, rates and currencies.
- [Financial markets data](financial-markets-data.md): yields, exchange rates, property and credit.
- [Household finance data](household-finance-data.md): public survey datasets, earnings and household expenditure.
Formats
CSV ZIP: download and extract the CSV. DIRECT CSV: open or save the CSV. EXPORT INTERFACE: open the dataset/table, filter and export. These links point to data, not just research articles.

Do not upload a downloaded third-party dataset into this repository unless redistribution is permitted. Record dataset version, retrieved date, units, geography, and license.
